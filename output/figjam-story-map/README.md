# Mimo story map

[Open the editable FigJam section](https://www.figma.com/board/AYNNAqQDARTmwlsa6AYHsd?node-id=568-3620).

Created 16 October 2026 from the existing Linear map and the user's classroom photo format. The section contains eight features, 26 user stories, 13 enablers and ten NFRs, with links to all 57 Linear issues.

The map uses persona activity rows, yellow stories, orange enablers, blue release/MMF boundaries, release name/goal cards, and an NFR lane. Seven MMFs across three releases are proposals for review. Existing frontend simulations remain distinct from proposed production services.

- `manifest.json`: node mappings, counts, release/MMF structure and verification.
- `overview.png`: final rendered overview.
- `mmf1.png`: first MMF detail.
- `nfrs.png`: quality requirements detail.
- `../linear-story-map/board-data.json`: story, enabler, NFR and source-link data.
- `../linear-story-map/story-map-reference.png`: local viewing conversion of the supplied reference.

Verification checked saved counts, links, section containment and sibling text overlap, plus rendered layout. It does not establish usability, production readiness or completion of the proposed features.
