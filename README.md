# SKEMA project learning

Public repository: [matthieu-pm/skema-project-learning](https://github.com/matthieu-pm/skema-project-learning).

The interactive Mimo onboarding prototype is in `app/`.

```sh
cd app
npm ci
npm run dev -- --host 0.0.0.0 --port 4173
```

Open http://localhost:4173. See `app/README.md` for scope and source details, and `app/design-qa.md` for verification. Original mascot assets remain in `all-models-and-images/`.

See `context.md` for project scope, research synthesis, design links, and current limitations. The raw participant interview snapshot is kept locally and is not included in this public repository.
