# Landing typography

The landing uses Labil Grotesk upright variable, copied from the user’s installed `~/Library/Fonts/LabilGroteskVariable-Upright.ttf` following their explicit request on 6 October 2026. It is served locally and preloaded. Existing Nunito files record the earlier design; the phone onboarding now shares the Labil Grotesk variable font following the later prototype request on the same date.
