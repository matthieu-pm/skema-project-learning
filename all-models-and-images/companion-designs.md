# Start & Setup — Companion edition

[Figma designs](https://www.figma.com/design/w4nc4L3hNF63uh2HBX9Np5?node-id=27-1319)

24 editable mobile screens, four original fuzzy 3D rendered companions, and static pets. All previous pet animations and screen transitions have been removed. Previous designs are preserved on Archive · Start & Setup v1. The old motion atlas has been removed.

The prototype walks through sample values; text entry, uploads, teacher search and external verification are design handoffs, not live services. Editable 3D models are in blender/companions.blend.

## Characters

- Mimo: green; learner guide
- Luma: lilac; teacher guide
- Pip: yellow; goals and encouragement
- Nori: blue; account setup and trust

Assets created with the built-in image-generation tool. See pets/prompts.md for exact prompts, and pets/ for transparent PNGs.
